# Заметка разработчика: намеренный дефект

Эту заметку передавать Ярославу для интеграции. Для первичного тестирования можно передать тестировщикам только исходный код и README со спецификацией.

Функция: count_russian_vowels.

Контракт: считать русские гласные, включая ё, без учёта регистра.

Намеренная ошибка: текущая реализация распознаёт только строчные буквы, потому что входной символ не приводится к одному регистру.

Проверочный пример:
- Вход: АаЁё
- Ожидается по контракту: 4
- Текущая реализация возвращает: 2

При тестировании это должно проявиться как обычное несоответствие фактического результата спецификации. После получения отчёта функция подлежит исправлению.
