# Строковый модуль — часть Саади

Практическая работа № 2: модульное и мутационное тестирование.
Язык — Python. Этот пакет содержит личный вклад Саади: пять функций обработки строк.
В одной функции оставлен предусмотренный заданием логический дефект.

## Функции и ожидаемое поведение

1. **count_words(text)** — считает слова, разделённые одним или несколькими пробельными символами. Пустая строка и строка из пробелов дают 0.
2. **reverse_text(text)** — возвращает строку с символами в обратном порядке.
3. **count_russian_vowels(text)** — считает русские гласные а, е, ё, и, о, у, ы, э, ю, я без учёта регистра.
4. **normalize_spaces(text)** — заменяет каждый непрерывный фрагмент пробельных символов одним обычным пробелом и убирает пробелы по краям. Пустая строка остаётся пустой.
5. **count_substring(text, part)** — считает непересекающиеся точные вхождения part с учётом регистра. Если part пустая, результат — 0.

Все функции ожидают строки типа str. Сторонние библиотеки не нужны.

## Запуск

Положите этот файл в Python-проект и импортируйте нужные функции из saadi_strings.
Чтобы выполнить будущий набор тестов проекта, из корневой папки запустите:

    python -m pytest -q

В этом пакете тестового набора пока нет: по плану его подготовят Артём и Влад для всего строкового модуля.
